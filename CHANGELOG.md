# Changelog

## Unreleased

- Added English and Polish translations that follow the Home Assistant profile language. English is the fallback.
- Added English versions of the Markdown documentation.

## 1.0.1 (2026-11-20)

- Reduced unnecessary background redraws during Home Assistant updates and while animation is disabled.
- Added a manually triggered release workflow that updates the version and documentation.

## 1.0.0 — first stable release (2026-11-18)

- First stable version of Dynamic Weather Background, based on code used in Home Assistant.
- Weather animation engine, visual editor, live diagnostics, and card appearance effects.
- Installation, configuration, and migration documentation with a YAML example.
- HACS / Marketplace manifest and MIT license.
- Renumbered the earlier development build to 1.0.0 with the same functionality.

Earlier versions, including the internal 1.7.1, were development builds.

- Pierwsza stabilna wersja Dynamic Weather Background, zbudowana na kodzie sprawdzonym w Home Assistant.
- Pełny silnik animacji pogody, edytor wizualny, diagnostyka i efekty wyglądu kart.
- Dokumentacja konfiguracji, instalacji, migracji i przykład YAML.

Wcześniejsze wersje (w tym wewnętrzna 1.7.1) były iteracjami rozwojowymi/alpha/beta i nie stanowią stabilnych wydań.
